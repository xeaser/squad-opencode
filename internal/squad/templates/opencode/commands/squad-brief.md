Give the human their daily brief.

1. Run `squad-oc brief` in the project root (add `--json` only if they asked for machine-readable).
2. Present every section. Do not invent tickets, PRs, or priorities that the command did not print.
3. If a source is `unavailable`, say so and continue.
4. Keep it scannable (short bullets).
